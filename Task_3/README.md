
# Parking Spot Reminder App

## CodeAlpha Internship – Task 3

**Task:** Interactive Prototyping

### Project Overview
A mobile application that helps users save their parking locations and receive reminders to find their parked cars easily.

### Project Deliverables
- Interactive Mobile App Prototype
- Screen Navigation
- Clickable Buttons and Interactions
- User Flow Demonstration
- Figma Prototype Link

### Design Tool
Figma

### Prototype Overview
The prototype demonstrates the main user journey, including saving a parking location, setting reminders, and accessing saved parking information.
